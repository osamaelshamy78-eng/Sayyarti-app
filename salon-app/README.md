# Salon Queue MVP

Standalone MVP for the salon marketplace + live queue concept. This folder is intentionally isolated from the existing Karajy application.

## MVP scope
- Customer: men/women categories, salon discovery, salon profile, services/prices, live queue status.
- Salon: dashboard for services/prices and live queue updates.
- No payments, commissions, or monetization in this phase.
- Salon-owned services/prices and queue status.
